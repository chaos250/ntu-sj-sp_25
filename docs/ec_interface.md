# 视觉 → 电控:通信数据、坐标与方向约定

> 适用程序:**mt_standard**(当前车上实际运行的主程序,由 watchdog 默认拉起)。
> 本文档只描述**当前运行框架**实际使用的数据;视觉侧旧协议(0xA5 帧)与哨兵 CAN 通道不在本车通信路径上,忽略即可。

**核心一句话:视觉发给电控的 yaw / pitch 是"世界系下的绝对目标角",参考系 = 电控发来的四元数 q 所定义的世界系。电控收到后直接做绝对角闭环,不要当相对增量。单位一律弧度 rad。**

## 1. 物理层与总览

| 项 | 约定 |
|---|---|
| 接口 | USB CDC 虚拟串口,波特率 **115200**,8N1 |
| 字节序 | 全部**小端**;结构体 1 字节 packed,无填充 |
| 频率 | 视觉 → 电控:**约 500 Hz**(每 2 ms 一帧);电控 → 视觉:按 1 kHz 实现 |
| CRC | CRC16,init `0xFFFF`,反射多项式 `0x1021`,覆盖 crc 字段之前的所有字节,结果按小端存放(见第 9 节) |
| 上电顺序 | **先电控、后视觉**。视觉启动后 3 s 内未收到电控首帧只打告警继续运行,收到首帧后自动进入正常流程 |

## 2. 视觉 → 电控 帧(VisionToGimbal,29 字节)

| 偏移 | 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|---|
| 0 | head[0] | uint8 | — | 帧头 `'S'` = 0x53 |
| 1 | head[1] | uint8 | — | 帧头 `'P'` = 0x50 |
| 2 | mode | uint8 | — | **0 不控制 / 1 控制云台但不开火 / 2 控制云台且开火**(见第 6 节) |
| 3 | yaw | float | rad | 世界系目标绝对方位角,**左正右负**(见第 4 节) |
| 7 | yaw_vel | float | rad/s | 前馈预留,当前主程序恒为 0(见第 7 节) |
| 11 | yaw_acc | float | rad/s² | 前馈预留,当前恒为 0 |
| 15 | pitch | float | rad | 世界系目标绝对俯仰角,**上负下正,负 = 抬枪**(见第 5 节) |
| 19 | pitch_vel | float | rad/s | 前馈预留,当前恒为 0 |
| 23 | pitch_acc | float | rad/s² | 前馈预留,当前恒为 0 |
| 27 | crc16 | uint16 | — | 覆盖偏移 0~26 的所有字节,小端 |

C 定义:

```c
#pragma pack(push, 1)
typedef struct {
  uint8_t  head[2];        // {'S','P'}
  uint8_t  mode;           // 0 不控制 1 控制不开火 2 控制且开火
  float    yaw;            // rad, 世界系目标绝对方位角, 左正右负
  float    yaw_vel;        // rad/s, 前馈预留(当前恒 0)
  float    yaw_acc;        // rad/s², 前馈预留(当前恒 0)
  float    pitch;          // rad, 世界系目标绝对俯仰角, 上负下正(负=抬枪)
  float    pitch_vel;      // rad/s, 前馈预留(当前恒 0)
  float    pitch_acc;      // rad/s², 前馈预留(当前恒 0)
  uint16_t crc16;          // 小端, 覆盖本字段之前所有字节
} VisionToGimbal;          // sizeof == 29
#pragma pack(pop)
```

## 3. 坐标系与参考系

发送的 yaw / pitch 是**绝对角**,参考系 = 电控发来的 q 所定义的**世界系**。视觉侧计算链:

```
相机系(OpenCV 右手系:x 右、y 下、z 前)
   ↓ 相机安装外参 R_camera2gimbal / t_camera2gimbal(标定好的固定值)
云台系(gimbal)
   ↓ 电控发来的四元数 q
世界系(绝对系)── yaw / pitch 在这个系里定义
```

世界系轴向由电控 q 的参考系决定。按约定取 **x 前、y 左、z 上(右手系)**:q = (1,0,0,0)(单位四元数)时,世界系 = 云台零位系。

> ⚠️ 当前视觉侧将"云台体系 = IMU 体系"作为前提。因此**电控发来的 q 必须是"云台体 → 世界"的旋转**;若 IMU 与云台体有安装夹角,请在电控固件里先换算成云台体姿态再发。
>
> q 格式要求:**顺序 w x y z,模长必须为 1**(视觉会校验,无效则沿用旧姿态)。

## 4. yaw 方向约定

- 计算:`yaw = atan2(y_world, x_world) + yaw_offset`(yaw_offset 是视觉侧标定偏置,见第 10 节)
- 值域:**[-π, π]**(atan2 天然输出,没有 wrap 到 0~2π;电控做差/闭环时请处理 ±π 跳变,用最短角差)

| 目标位置 | 收到的 yaw | 云台应做的动作 |
|---|---|---|
| 正前方 | ≈ 0 | 不动 |
| 偏**左** | **> 0** | 向左转 |
| 偏**右** | **< 0** | 向右转 |

## 5. pitch 方向约定

- 计算:`pitch = -(弹道俯仰角 + pitch_offset)`,其中弹道俯仰角 = 目标相对水平面的仰角(向上为正,含重力补偿)
- 符号:**负 = 抬枪,正 = 压枪**

| 目标位置 | 收到的 pitch | 云台应做的动作 |
|---|---|---|
| 高于水平面 | **< 0** | 抬枪 |
| 低于水平面 | **> 0** | 压枪 |

- 正常弹道解算范围内 |pitch| 一般 < 45°(0.78 rad)。
- 若电控 pitch 电机编码器的正方向与此相反(不少板子"下压为正"),**在电控固件里取反即可**,不要怀疑视觉数据错。

## 6. mode 语义与电控侧要求

| mode | 含义 | 视觉侧触发条件 |
|---|---|---|
| 0 | 不控制 | 未收到电控自瞄指令、目标短暂丢失(亚秒级)、或 yaw/pitch 为 NaN/Inf 等无效值 |
| 1 | 控制云台但不开火 | 有目标在跟踪,但未满足开火判定 |
| 2 | 控制云台且开火 | 有目标、开火开关开启、云台已跟上目标(误差在容差内) |

电控侧约定:

- 收到 **mode 0** 后:保持 / 回中 / 停控由电控决定,但**不得执行视觉停控前最后一帧的旧指令**;视觉在断流、丢帧、数据无效时都会自动改发 mode 0。
- 建议电控侧加**帧超时看门狗**:连续 10 ms 以上未收到有效帧,即停止执行视觉指令并转电控自身保护逻辑。

## 7. 前馈字段

当前主程序只发位置量,**yaw_vel / yaw_acc / pitch_vel / pitch_acc 恒为 0**,电控按预留字段解析即可。若未来启用,单位与符号同 yaw / pitch(绝对角速度 rad/s、角加速度 rad/s²)。

## 8. 电控 → 视觉 帧(GimbalToVision,43 字节)

| 偏移 | 字段 | 类型 | 单位 | 要求 |
|---|---|---|---|---|
| 0 | head[0] | uint8 | — | `'S'` = 0x53 |
| 1 | head[1] | uint8 | — | `'P'` = 0x50 |
| 2 | mode | uint8 | — | 0 空闲 / 1 自瞄 / 2 小符 / 3 大符。**发 1 后视觉才开始检测与控制**(当前主程序只响应 1,2/3 预留) |
| 3 | q[4] | float×4 | — | 云台体→世界四元数,**顺序 w x y z,模长 = 1** |
| 19 | yaw | float | rad | 云台当前绝对 yaw,符号与 q 参考系一致 |
| 23 | yaw_vel | float | rad/s | 云台 yaw 角速度 |
| 27 | pitch | float | rad | 云台当前绝对 pitch |
| 31 | pitch_vel | float | rad/s | 云台 pitch 角速度 |
| 35 | bullet_speed | float | m/s | **必须回传真实弹速**;<14 m/s 视为无效,视觉改用配置兜底弹速(当前 23.0,**联调前务必改为实测值**)并告警 |
| 39 | bullet_count | uint16 | — | 累计发弹数 |
| 41 | crc16 | uint16 | — | 覆盖偏移 0~40 的所有字节,小端 |

C 定义:

```c
#pragma pack(push, 1)
typedef struct {
  uint8_t  head[2];        // {'S','P'}
  uint8_t  mode;           // 0 空闲 1 自瞄 2 小符 3 大符
  float    q[4];           // 云台体->世界, 顺序 w x y z, 模长=1
  float    yaw;            // rad
  float    yaw_vel;        // rad/s
  float    pitch;          // rad
  float    pitch_vel;      // rad/s
  float    bullet_speed;   // m/s, 必须真实值
  uint16_t bullet_count;   // 累计发弹数
  uint16_t crc16;          // 小端, 覆盖本字段之前所有字节
} GimbalToVision;          // sizeof == 43
#pragma pack(pop)
```

注意事项:

- yaw / pitch / yaw_vel / pitch_vel 请填**云台真实姿态**(云台停零位时 ≈ 0 属正常),不要留 0 或垃圾值。
- 发送前 `memset` 清空缓冲,勿发送未初始化内存。
- 用 `offsetof` 逐字段核对结构体偏移(尤其 q 之后的部分),确保与上表一致。

## 9. CRC16 参考实现

位运算版(与视觉侧查表版完全等价):

```c
uint16_t crc16_update(uint16_t crc, uint8_t byte) {
  crc ^= byte;
  for (int i = 0; i < 8; i++)
    crc = (crc & 1) ? (crc >> 1) ^ 0x8408 : crc >> 1;
  return crc;
}

// 用法:初值 0xFFFF,对帧头到 crc 字段之前的所有字节依次 update
uint16_t crc = 0xFFFF;
for (i = 0; i < len_before_crc; i++) crc = crc16_update(crc, frame[i]);
```

**测试向量:`"123456789"` → `0x6F91`;`"SP"` → `0x5BA2`。** 联调前两边各算一遍对表。

> 当前视觉侧配置 `crc_check: false`(暂不校验回传帧 CRC);电控实现并回传 CRC 后,视觉侧会改回校验。

## 10. 视觉侧标定偏置(视觉参数,联调可能调整)

| 配置项 | 当前值 | 单位 | 用途 |
|---|---|---|---|
| yaw_offset | 2 | 度 | 整体 yaw 修正(装配误差、相机安装角、世界系 x 轴不一致) |
| pitch_offset | 6.5 | 度 | 整体 pitch 修正 |
| default_bullet_speed | 23.0 | m/s | 电控帧内弹速无效时的兜底弹速 |

这些是视觉侧参数,电控固件**不要硬编码假设**。注意:offset 只能修"常值偏差";若实测云台转向与预期**镜像相反**,是 q 参考系 / 电机正方向问题,改电控侧,调 offset 没用。

## 11. 静态对表(联调必做,一次说清)

前提:云台放零位,电控发 q(发单位四元数即可开始对)。

| 操作 | 视觉发送预期 | 云台应做的动作 |
|---|---|---|
| 靶放**正前方** | yaw ≈ 0 | 不动 |
| 靶放**偏左** | yaw > 0 | 向左转 |
| 靶放**偏右** | yaw < 0 | 向右转 |
| 靶**抬高** | pitch < 0 | 抬枪 |
| 靶**放低** | pitch > 0 | 压枪 |

排错:

- **左 / 右反了** → 电控检查 q 的参考系与电机正方向;
- **差一个固定角度** → 视觉侧调 `yaw_offset` / `pitch_offset`;
- **数值对但云台乱动 / 不执行** → 查 mode 0 的处理与帧超时看门狗。
